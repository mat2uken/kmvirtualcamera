# ADR 0003: 送信側 Web UI における VanJS + Open Props の採用

## ステータス
承認済 (Accepted)

## 背景 (Context)
ブラウザ送信側（`/send/`）のUIについて、依存関係の極限最小化と高速なロード時間、高水準なデザイン・操作性を両立する必要があります。重量級のReactランタイムやCSS-in-JSを排除しつつ、リアクティブな状態管理と洗練されたモダンデザインを実現する構成が求められています。

## 決定事項 (Decision)
1. **リアクティブ UI ライブラリ**:
   - **`VanJS`** (`vanjs-core`) を採用する。
   - `VanJS` はわずか 0.9kB の極小・超高速なリアクティブ UI ライブラリであり、仮想DOMのオーバーヘッドなく標準DOMを直接リアクティブに操作できる。
   - TypeScriptとの親和性が極めて高く、ビルド後のフットプリントを最小限に抑えられる。
2. **デザインシステム・スタイリング**:
   - **`Open Props`** (`open-props`) を採用する。
   - `Open Props` はモダンな CSS Custom Properties（CSS変数）ベースのデザイントークン集であり、JavaScriptランタイムを一切消費せず、タイポグラフィ、カラーパレット、トランジション、シャドウ、レスポンシブレイアウトを美しく実現できる。

## 影響 (Consequences)
- **メリット**:
  - 送信ページのバンドルサイズが数十KB以下に劇的に縮小し、モバイルブラウザでの初期ロードが瞬時に完了する。
  - Reactなどの大型ランタイムが不要となり、プロジェクトの「依存極限最小化」方針と完全に合致する。
  - Open Props により、高品質で一貫性のあるモダンなUIデザイン・アニメーションをピュアCSSで実現できる。
